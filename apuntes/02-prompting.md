# Prompting y protocolo

Un prompt de sistema establece el rol, las restricciones y el formato obligatorio de salida. Un protocolo textual JSON permite conectar el modelo con herramientas sin function calling nativo. Cada respuesta contiene una sola acción.

Las instrucciones claras reducen ambigüedades. Conviene pedir una acción concreta y especificar cuándo finalizar. También se deben comprobar las entradas y no aceptar instrucciones externas que contradigan las reglas del sistema.
