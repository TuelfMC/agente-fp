# Subnetting

Un prefijo CIDR indica cuántos bits pertenecen a la red. Por ejemplo, /26 reserva 26 bits y deja 6 para hosts. La fórmula general ofrece 2^h direcciones totales, de las cuales dos no sirven como hosts individuales en una subred tradicional.

Para 192.168.1.0/26 existen 64 direcciones: 62 utilizables, desde 192.168.1.1 hasta 192.168.1.62. La dirección 192.168.1.0 es la red y 192.168.1.63 es difusión.
