# Redes y sistemas

Una dirección IP identifica una interfaz dentro de una red. Una máscara separa la parte de red de la parte de host. Los protocolos TCP y UDP transportan datos sobre IP y usan puertos para identificar servicios.

HTTP usa habitualmente el puerto 80 y HTTPS el 443. DNS usa el puerto 53, SSH el 22 y SMTP el 25. Un firewall puede aceptar, rechazar o descartar tráfico según dirección, puerto y protocolo.
